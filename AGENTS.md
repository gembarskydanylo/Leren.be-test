# Leren.be-test working rules

- This repository is the test app. Do not publish these experiments to Leren.be / lerenbe.com unless the human explicitly asks to transfer them.
- The user requires a durable record of every addition and test. Update TESTING-JOURNAL.md in the same change: Brussels date/time, experiment ID, concrete behavior, files, checks actually performed, results, limitations and deployment/commit references.
- Keep PRODUCTION-TRANSFER.md current with dependencies, storage migrations, integration points and experiments approved or still awaiting user evaluation. A test release is not approval to migrate it.
- Record unsuccessful checks and their fixes honestly. Never describe simulated speech or network tests as physical-phone/live-service verification.
- Preserve existing course/card IDs and legacy progress. Keep experiment notes free of user messages, microphone recordings, credentials and other personal test data.
