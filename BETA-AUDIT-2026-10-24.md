# Leren.be-test: перевірка 24.10.2026

Базова версія: `2c641ae`, репозиторій `gembarskydanylo/Leren.be-test`.

## Підтверджені помилки та виправлення

- Відсутній `modules/belgium-lab/lab.js` завантажувався головною сторінкою, сторінкою для друку та офлайн-кешем. Через помилку `cache.addAll` не завершувалася інсталяція service worker. Прибрано посилання на неіснуючий модуль; нову функціональність Belgium Lab не вигадували.
- Старий workflow для виправлення HTML глобально замінював закривальні теги, включно зі справжнім тегом поза шаблоном. Замість автоматичного переписування сторінки він запускає перевірки з правами лише читання.
- Перевірка версії могла отримати старий `sw.js` із кешу. Додано унікальний параметр запиту й обхід кешу для перевірок версії та `no-store`. Версія кешу — 87; точний URL даних курсу закешований для офлайн-режиму.
- Стартове повідомлення основного застосунка обіцяло 15 питань замість 12; число тепер береться з тесту. Значення прогресу для допоміжних технологій синхронізоване з візуальною смугою.
- Некоректна збережена мова, пошкоджений JSON, неправильні типи стану або недоступне сховище могли зупинити щоденний урок. Додано перевірку та безпечне читання/збереження.
- Повторне проходження теми скидало всі її інтервали повторення. Наявний графік тепер зберігається; нові фрази додаються окремо.
- Повторні виклики обробника відповіді могли повторно зарахувати бал або перейти через наступну картку повторення. Додано захист від повторної обробки.
- Діалоги використовували перші два слова теми, наприклад «Eén — Twee». Для всіх 12 тем додано відповідні короткі запитання й відповіді з українським перекладом.
- Щоденний модуль позначав свої 12 тем як A1.1 + A1.2, хоча використовує лише A1.1. Позначення виправлено; українські назви тем тепер описують тему, а не переклад її першого слова.
- За невдалого завантаження даних курсу тепер показується екран повторної спроби замість порожнього маршруту.

## Перевірено

- `beta-daily`, `runtime-smoke`, `curriculum`, `code-audit`, `clock`, `push-permissions`, `widgets` — пройшли.
- У браузері пройдено новий урок: слова → слухання → тест 3/3 → тематичний діалог → повторення → завершення. Після перезавантаження збереглися завершена тема та вибрана мова. У цьому сценарії журнал JavaScript без помилок.
- У маніфестах аудіо є 4605 чоловічих і 4600 жіночих записів; відповідні файли `.m4a` існують.
- Основний репозиторій Leren.be і модуль дифтонгів не змінені.

## Наявні обмеження бети

Це короткі вступні заняття A1.1, а не повний новий курс A1.1/A1.2. Повний переклад нового модуля англійською, французькою та арабською ще не реалізований: вибір мови перекладає початковий екран, уроки залишаються українською, про що бета повідомляє.

Основний застосунок у тестовому репозиторії досі містить налаштування Firebase/AI основного проєкту, як зазначено в README бети. Особистий акаунт, хмарна синхронізація та доставка push не перевірялися на реальних даних. Конфігурацію цих сервісів у цьому виправленні не змінювали.
