## Обмеження й Samsung

- Фізичний Samsung, сенсорна клавіатура, Android Back, TalkBack, системний великий шрифт, реальне встановлення PWA та запуск із домашнього екрана не перевірялись. CDP-спроба емуляції standalone не активувала display-mode; не зарахована.
- Озвучення й відсутність запису мають технічні перевірки, але якість звуку на реальному динаміку/наявність голосу nl-BE не оцінювались. Мікрофон, Firebase, авторизація та зовнішній AI не викликались.
- Короткі текстові посилання в посібниках і LIFE лишаються inline; немає твердження, що кожне посилання у застосунку має 44×44 px.
- Носій фламандського варіанта не залучався; noindex не змінено. Посібники досі потребують editorial/canonical перед індексацією.
- Блокерів у навчальному рушії, Firebase, авторизації чи безпеці під час цього аудиту не виявлено; для Claude Code нових завдань немає. Архітектуру не змінювали.
