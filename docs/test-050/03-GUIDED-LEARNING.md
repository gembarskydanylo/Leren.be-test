## Автоматичне навчання: детермінований алгоритм без AI

Вхід: `leren_path_v1` (поточний курс), `due` (слова, яким настав час повторення), `leren_mistakes`, `pace`, `leren_goal_min`, хвилини за сьогодні.
Вихід: план заняття з 1–4 кроків. **AI у виборі кроків не бере участі.**

```
planToday():
  1. Перерваний урок (state.session)           → «Продовжити урок» і більше нічого.
  2. Тест рівня розпочато (state.placement)    → «Продовжити тест».
  3. Розминка: warmupIds(due) ≥ 3 і сьогодні ще не було (state.warmed ≠ today)
                                               → крок «Повторення · N слів» (≤ 5 слів, без XP).
  4. Наступний урок: recommended() у поточному курсі → крок «Урок · тема, частина k».
     pace = intensive → ще й наступний урок після нього.
  5. pace ≠ calm → «Коротка гра» на слова цього уроку (наявні ігри за тегом теми; немає підходящої — крок пропускаємо).
  6. Кінець розділу → тест теми (наявна перевірка розділу).
  7. Курс завершено → пропозиція наступного курсу (A1.1 → A1.2).
     Після A1.2: «A2 — 1 розділ (у розробці)» і повторення.
```

**Поведінка після кожного кроку:**
- Після кроку план переходить до наступного сам: екран «Готово → далі: …» і через 1,5 с або натисканням починається наступний крок.
- Коли мету дня виконано, показуємо «Мету виконано. Ще один урок?». Можна завершити.

**Збереження.** `advance()`, `nextPhase()` і `finish()` записують `leren_path_v1` після **кожної** відповіді й фази. Новий лише покажчик кроку в плані: `state.today = {date, steps, at}`.
Перезавантаження посеред заняття повертає на той самий крок і ту саму картку. Поведінка 264 при цьому не змінюється: ядро маршруту залишається як є.

**XP без повторів.**
- Бали за урок вже нараховуються лише за новий особистий рекорд (`leren_path_rewards_v1[id]`).
- Повторення XP не дає.
- Додаємо захист: кожен крок плану має id `date:kind:lessonId`, і бали за крок нараховуються, лише якщо такого id ще немає в `state.today.paid`. Так подвійне натискання, повернення «Назад» або перезавантаження після нарахування не дають XP вдруге.

**Офлайн.**
- Усе потрібне для плану (`course-curriculum.js`, модулі, картки, аудіо поточного уроку) вже лежить у кеші Service Worker.
- Вкладка «Сьогодні» не робить мережевих запитів.
- Картка Lexi офлайн показує локальний текст і позначку «Потрібен інтернет» на кнопці чату (`lexiBlocked`).

**Ручний вибір.** «Обрати урок самостійно» на «Сьогодні» відкриває вкладку «Навчання».
Учень може будь-коли почати будь-який урок через `begin(id)`. Тоді план дня перебудовується від нього.

**Цілі (`goals`) у першій версії** не змінюють порядок курсу, бо теми A1 спираються одна на одну. Вони впливають лише на:
- приклад у картці Lexi;
- порядок рекомендованих сценаріїв Lexi та історій Life (робота → `a2work` і сценарії про роботу; Бельгія → документи, лікар, житло).

## Схема

```
Відкриття застосунку ─► firstRun()
   ├─ новий учень ─► онбординг 5 екранів ─► openFirstLesson / openStartCheck
   └─ наявний ────► «Сьогодні» (+ разове запрошення назватися)
                         │ planToday() — без мережі
                         ▼
   [Повторення] → [Урок: Вчимо → Слухаємо → Перевіряємо] → [Коротка гра] → «Готово»
        │ кожна відповідь зберігається в leren_path_v1     │ XP — лише новий рекорд + paid[]
        ▼                                                   ▼
   Мету дня виконано? ── так ─► «Ще один урок?» / завершити
                    └─ ні ──► наступний крок автоматично
```
