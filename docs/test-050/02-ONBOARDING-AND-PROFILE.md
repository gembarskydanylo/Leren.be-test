# TEST-050 · Фази 3–5. Онбординг, наявні учні, вік, профіль

Макети: полотно «LerenBe TEST-050 макети», ряд «Знайомство з Lexi і наявні учні».

## Онбординг нового учня: 5 екранів, ≈ 1 хвилина

Показуємо лише тоді, коли `hasLearningHistory()` = false і `leren_welcome_seen` ще не встановлено.
На кожному екрані є «Пропустити». Будь-який пропуск зберігає вже зібрані відповіді й **одразу відкриває перший урок**.

| № | Екран | Що зберігаємо | Звідки береться |
|---|---|---|---|
| 1 | «Привіт! Я Lexi» + мова пояснень | мова інтерфейсу (`changeUiLang`) | крок 1 `welcomeNl` |
| 2 | «Як я можу до тебе звертатися?» | `name`, `nameForAI` | новий |
| 3 | Мета, кілька варіантів: Життя в Бельгії, Робота, Навчання, Спілкування, Подорожі, Для себе | `goals[]` | новий |
| 4 | Рівень: Починаю з нуля / Уже трохи знаю (→ тест на 12 питань або основи) / Оберу рівень сам | `leren_start_known_v1`, тест — `startPlacement` | кроки 2–3 `welcomeNl` |
| 5 | Мета дня 5/10/15/20 хв і темп: Спокійний / Збалансований / Інтенсивний | `leren_goal_min`, `pace` | мета — є, темп — новий |

**Що відбувається після екрана 5:**
- «Починаю з нуля» або «основи» → `openFirstLesson()`;
- тест → `openStartCheck()`;
- «Оберу сам» → вкладка «Навчання» з вибором рівня.

**Рівні на екрані 4.** Пропонуємо тільки A1.1 і A1.2. A2 позначаємо як «1 розділ, у розробці». Повного курсу A2 не обіцяємо.

**Ім'я:**
- **Unicode:** «Марія», «Mohammed», «محمد», «Zoë» тощо. Без фільтра «лише латиниця».
- **Обробка:** `trim`, нормалізація NFC; керівні символи й `<>{}` видаляються; ≤ 40 символів.
- **Порожнє** ім'я — нормальний стан.
- **На екрані:** тільки через `textContent`, ніколи через `innerHTML`.
- **У тексті інтерфейсу** — лише у формі звертання без відмінювання: «Привіт, Марія!».
  Український кличний відмінок («Маріє») автоматично не будуємо: для довільних імен він дає помилки.

## Наявні учні (фаза 4)

**Ознака наявного учня:** `hasLearningHistory()` = true або `leren_tour_done` / `leren_welcome_seen` уже встановлено.
Такий учень не проходить онбординг повністю.

**Запрошення назватися:**
- Якщо `profile.name` порожнє, а `profile.namePrompt` не дорівнює `later` чи `done`, на вкладці «Сьогодні» один раз з'являється картка:
  «Привіт! Ми вже знайомі, але я ще не знаю, як тебе звати. Як мені до тебе звертатися?» з кнопками **Ввести ім'я** / **Пізніше**.
- Це картка, а не модальне вікно. Вона не з'являється:
  - під час уроку;
  - разом з банером оновлення Service Worker;
  - у той самий день, коли учень бачить банер змін релізу.
- **Пізніше** → `namePrompt = "later"`: картка більше не з'являється. Ім'я можна додати в «Ще → Профіль».
- **Ввести ім'я** → поле прямо в картці → `namePrompt = "done"`.

**Що не змінюється:**
- XP і бали;
- прогрес уроків і курсів (`leren_path_v1`, `@en` / `@fr`);
- досягнення;
- мови інтерфейсу й навчання;
- голоси (`leren_rec_voice`, `leren_voice_*`, `leren_char`);
- налаштування доступності, тема, швидкість мови.

Профіль лише **додає** новий ключ і ніде не перезаписує старі.

**Цілі й темп для наявних учнів:** не питаємо. За замовчуванням темп `balanced`, мета дня — та, що вже збережена. Змінити можна в «Ще → Профіль».

## Вік (фаза 5): рекомендую **не збирати** у першій версії

1. **Що вік мав би дати:**
   - адаптацію: її краще будувати на результатах, помилках, повтореннях, темпі й цілях;
   - доступ до AI-чату: він уже закритий галочкою «мені є 18» (`leren_ai_consent18`) у згоді на AI.
2. **Ризики:**
   - навіть вікова група — персональні дані (GDPR, ст. 4);
   - позначка «до 18» означає, що ми **знаємо** про неповнолітнього. Тоді діє ст. 8 GDPR (у Бельгії вік цифрової згоди 13 років) і посилені вимоги до акаунта й синхронізації з Firebase;
   - вік легко сприйняти як оцінку здібностей, а це заборонено умовою TEST-050.
3. **Висновок:** вікову групу не питаємо. Галочка 18+ лишається там, де вона є, — на вході в AI-чат.
   Учні молодше 18 користуються всім, крім AI-чату, як і зараз.

## Схема профілю: новий ключ `leren_profile_v1`

```json
{
  "v": 1,
  "goals": ["belgium", "work"],
  "pace": "balanced",
  "namePrompt": "done",
  "onboarded": "2026-11-24",
  "source": "new"
}
```

```json
{ "leren_learner_name": { "name": "Марія", "forAI": false } }
```

| Поле | Значення | Примітка |
|---|---|---|
| `goals` | підмножина `belgium, work, study, social, travel, self` | порожній масив — «не вказано» |
| `pace` | `calm` \| `balanced` \| `intensive` | за замовчуванням `balanced` |
| `namePrompt` | `null` \| `later` \| `done` | лише для наявних учнів |
| `onboarded` | дата | не час, не часовий пояс |
| `source` | `new` \| `existing` | звідки профіль: з онбордингу чи з міграції |
| `leren_learner_name.name` | рядок ≤ 40 | окремий ключ |
| `leren_learner_name.forAI` | `false` за замовчуванням | окрема згода на передачу в AI |

**Де зберігається:**
- `leren_profile_v1` синхронізується з акаунтом, як інші налаштування, і потрапляє в резервну копію.
- `leren_learner_name` додаємо в **`SYNC_SKIP`**: ім'я лишається тільки на цьому пристрої й не йде ні у Firestore, ні в файл резервної копії.

  Плюс: ім'я ніколи не залишає телефон.
  Ціна: на новому телефоні Lexi спитає ім'я ще раз.

  Якщо ти хочеш, щоб ім'я синхронізувалося з акаунтом, це окреме рішення: тоді треба оновити `privacy.html`.

**Ще можна:** очистити ім'я в «Ще → Профіль» (ключ видаляється) і вимкнути `forAI` будь-коли.
