# Перевірка Lexi на фізичному Samsung (TEST-032 / TEST-034)

**Статус:** інструкцію підготовлено. **На телефоні ще нічого не запускали.** Результат можна вписати лише після фактичного проходження.

## Чому `localhost`, а не IP комп'ютера

Мікрофон, Service Worker і встановлення як PWA працюють лише в **захищеному контексті** (secure context):
- `https://…`;
- `http://localhost`.

Адреса на зразок `http://192.168.0.4:8765` захищеним контекстом **не є**. На ній Chrome не дасть мікрофон, не зареєструє Service Worker і не встановить PWA.

`adb reverse` вирішує це: телефон відкриває `http://localhost:8765`, а з'єднання через USB веде на сервер Mac.

## 0. Підготовка (один раз)

1. **Samsung:** Налаштування → Відомості про телефон → Відомості про ПЗ → 7 разів натиснути «Номер збірки». Потім «Параметри розробника» → увімкнути **Налагодження USB**.
2. Підключити кабель і дозволити налагодження для цього Mac.
3. **Mac:**

```bash
~/Library/Android/sdk/platform-tools/adb devices
```

Телефон має бути в списку зі статусом `device`, а не `unauthorized`.

## 1. Запуск

У клоні гілки з TEST-034:

```bash
node tools/lexi-test-server.cjs
```

```bash
~/Library/Android/sdk/platform-tools/adb reverse tcp:8765 tcp:8765
```

На телефоні в **Chrome**: `http://localhost:8765/app/?lexi=demo`

- **Демо-режим:** відповіді Lexi вигадані й позначені «Демонстрація». Нічого не надсилається, AI не викликається. Режим діє до закриття вкладки.
- **Реальний AI:** лише після окремого погодження й розгортання тестового Worker (`docs/LEXI-TEST-WORKER.md`). Тоді сервер запускають з `LEXI_TEST_WORKER=…` і один раз відкривають `http://localhost:8765/lexi-test.html`.
- **Консоль телефона на Mac:** Chrome → `chrome://inspect/#devices` → Inspect.

**Альтернатива без USB:** поки бета на GitHub Pages показує TEST-032 (`https://gembarskydanylo.github.io/Leren.be-test/app/?lexi=demo`), там теж https. Тож мікрофон, Service Worker і PWA працюють і там, але тільки в демо-режимі.

## 2. Що перевірити

Позначай ✅ / ❌ і для кожного ❌ роби скриншот.

### Чат і сценарії
- [ ] Ігри → «Поговорити з Lexi»: чат відкривається на весь екран, видно аватар Lexi.
- [ ] Перебрати 5 сценаріїв: Вільна розмова, Говоріння, Життєва ситуація, Граматика, Допомога в уроці. Для кожного надіслати повідомлення й отримати відповідь.
- [ ] Життєва ситуація: 6 ситуацій у списку.
- [ ] Мова навчання NL / FR / EN, мова пояснень UK / EN / FR / AR. Арабська — справа наліво.
- [ ] Рівні A1.1 / A1.2 / A2.1.
- [ ] Темна тема: кнопка в чаті та тема системи.
- [ ] Відкриється клавіатура: **чи видно поле введення й кнопку «Надіслати»?** Відома проблема: висока сторінка з прокруткою.
- [ ] Поворот екрана.

### Мікрофон (лише https або localhost)
- [ ] Кнопка мікрофона → Chrome питає дозвіл → **Заборонити**: Lexi пише, що доступ заборонено й можна написати текст.
- [ ] Дозволи сайту → Мікрофон → Дозволити → сказати «Ik woon in Gent»: розпізнаний текст з'являється в полі, його **можна виправити** перед надсиланням, нічого не надсилається саме.
- [ ] Під час запису кнопка «Зупинити» працює.
- [ ] Без мережі (режим польоту) розпізнавання в Chrome недоступне: має бути зрозуміле повідомлення, а не зависання.

### Озвучення
- [ ] «Озвучити» під відповіддю Lexi: голос нідерландський, якщо в Samsung встановлено голос NL. Інакше записати, який голос звучить.
- [ ] Озвучується саме те повідомлення, під яким натиснули кнопку.

### Кнопка «Назад» Android і навігація
- [ ] Системна кнопка/жест «Назад» у чаті закриває чат і повертає на попередній екран, а **не** виходить із застосунку.
- [ ] Повторне «Назад» працює як звичайно.
- [ ] Кнопка «←» у чаті робить те саме.

### PWA і офлайн
- [ ] Меню Chrome → «Додати на головний екран» / «Встановити застосунок». Іконка й назва LerenBe.
- [ ] Встановлений застосунок відкривається без адресного рядка.
- [ ] У встановленому застосунку чат показує, що Lexi вимкнена (демо-параметр туди не передається). Це очікувано для тесту.
- [ ] Режим польоту → відкрити застосунок: уроки працюють з кешу, чат пише «офлайн».
- [ ] Оновлення: після нового релізу перезапустити сервер, відкрити застосунок двічі — має завантажитися нова версія (номер у налаштуваннях).

### Доступність
- [ ] TalkBack: озвучуються кнопки чату, стан Lexi та нові відповіді.
- [ ] Великий шрифт (Налаштування → Дисплей → Розмір шрифту): нічого не обрізається.

### Регрес
- [ ] Урок → Вивчення / Тест / Аудіо: XP нараховується як раніше.
- [ ] Іспит A1.1 відкривається без помилки.
- [ ] LIFE відкривається.
- [ ] Відгуки й конфіденційність англійською: текст англійський.

## 3. Завершення

```bash
~/Library/Android/sdk/platform-tools/adb reverse --remove-all
```

Сервер зупинити клавішами Ctrl+C. Тестовий Worker вимкнути, якщо його вмикали (`docs/LEXI-TEST-WORKER.md`).
