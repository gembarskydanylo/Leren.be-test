| Review | Прогрес, пригадування перед відкриттям перекладу, приклад, дії «ще повторю» / «згадав». SRS не підключено |
| LIFE | Повноекранна сцена, люди Annick/Anastasia, діалогова панель, відповіді з перекладом, аудіокерування й крок 2/8. Одна статична сцена-пропозиція |

Chat state selector дає оглянути Welcome / Listening / Thinking / Speaking / Correct answer / Incorrect answer / Offline / API error. Ці стани доступні також у URL. Відповіді й feedback — заготовлені приклади, не AI-оцінка написаного тексту.

**Mock-межа:** приклад 20 XP / 1 урок, повідомлення, сценарії, мовні варіанти й результати існують лише в пам’яті сторінки. У URL зберігаються екран, тема, мова, рівень та обраний демонстраційний стан. Текст повідомлень не потрапляє в URL чи сховище. Reload очищує розмову. Мікрофон, TTS, API, Firebase, XP, SRS і Service Worker не використовуються. CSP забороняє connect/media; жодних зовнішніх залежностей.

Сценарії є короткими демонстраційними входами, а не повними діалоговими деревами. Фізичний запис/відтворення та реальна AI-перевірка не тестувалися й не заявляються готовими.

## Дизайн-система

- Світла B: теплий `#f6f2e9`, папір `#fffdf7`, чорнило `#173e33`, зелена основна дія `#225a45`.
- Темна C: тло `#15241f`, поверхня `#20352a`, світле чорнило `#f1f4e7`, тепла дія `#ecb284`.
- Nunito для читання; Unbounded для заголовків темної теми. Лише наявні локальні шрифти проєкту.
- Primary/secondary/icon buttons, course/language selects, cards, composer, numbered answers, semantic success/error/warning, аватари шести емоцій.
- Desktop rail на головній, чотири нижні вкладки на мобільному; навчальні екрани мають focus layout з явним виходом, чат — власну навігацію.
- Focus ring 3px; цілі 44px і більше; rem-типографіка й перенесення тексту при 200%; короткі переходи 160ms і хвиля аудіо. Reduced motion вимикає анімації/переходи.
- Не додано шарів до старих CSS: прототип завантажує тільки власні tokens.css/design.css. Старі компоненти/рушії не переписано.

Галерея показує сім Before/After з прямими посиланнями на повні PNG. Before знято саме з інтеграційної бази цього PR; чат — порожній локальний fixture без AI-запиту.

Виявлені й виправлені під час перевірки проблеми:

1. Intrinsic height master-зображення витягувала мобільне привітання на 768px: встановлено пропорції 1:1 і height:auto.
2. Подвоєний текст розпирала картки/відповіді: мінімальні ширини flex/grid, перенесення тексту й адаптивні групи без обрізання overflow.
3. Re-render забирав keyboard focus і чернетку: фокус відновлюється за дією/полем, чернетка існує в пам’яті незалежно від теми та помилкового стану.
4. Кнопки виходу без доступної назви: додано явне «Повернутися на головну».
5. Візуальний перегляд виявив literal `false` у порожніх маркерах Quiz/Audio та надмірно вузький плеєр: виправлено шаблон і ширину grid-кнопки; додано регресійні assertions. Саме проходження layout-тестів цього не виявляло.
6. Desktop LIFE надто високо кадрував портретну сцену: зміщено фокус так, щоб обидва обличчя залишалися між верхньою навігацією й діалоговою панеллю; повторний візуальний огляд 1440px.
7. Дрібне допоміжне письмо й коротка audit-link: збільшено примітки та ціль посилання до 44px.
