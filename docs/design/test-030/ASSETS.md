# TEST-030 — Lexi та графічні ресурси

## Статус

У Git-дереві інтеграції, TEST-027 і доступних проєктних матеріалах затвердженого Lexi не знайдено. Старий студентський кіт із шарфом і чорними очима не відповідає brief. Новий образ **PROPOSAL / очікує затвердження власника**. Це не заміна вже затвердженого еталона.

| lexi-master-proposal.webp | 768×768 | Рудий кіт, зелені очі, окуляри, темно-зелена кофта LerenBe; привітання | Новий AI-generated proposal |
| lexi-emotions-proposal.webp | 1536×1024 | Атлас 3×2, кожна комірка 512×512 | Новий AI-generated proposal |
| life-station-proposal.webp | 960×1440 | Статична сцена Gent-Sint-Pieters, Anastasia й Annick | Перетворення чернетки TEST-027, не затверджений runtime art |

Атлас: верхній ряд welcome / listening / thinking, нижній speaking / success / encourage. CSS використовує background-position, а не випадкові emoji. Offline/API error використовують encouragement і текстове повідомлення, не нового персонажа.

Згенеровано imagegen на підставі опису власника. Друге зображення створено з master як референсом для послідовності. WebP оптимізовано локально; вихідні PNG не включено, щоб не роздувати репозиторій. Затверджений HERO A/C використовується з чинних app/img/home/home-hero-{mobile,desktop}.webp лише для читання, без редагування.
