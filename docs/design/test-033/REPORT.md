# TEST-033 · Звіт: мобільний чат Lexi, повернені функції, AI-іспит у Concept B

Гілка `codex/test-033-lexi-mobile-ux` (від TEST-032 `a0428af`). Release / кеш **257** (256 — TEST-034, TEST-035 лишається на 255).

## 1. Мобільна клавіатура — прийнято власником (фізичний Samsung, Preview 3)
- Список попередніх фраз над клавіатурою був автозаповненням Chrome (поле `name="draft"`): `autocomplete="off"`. Підказки самої клавіатури Samsung від сторінки не залежать.
- Висота чату = видима частина (visualViewport); історія — єдина прокрутка; верхня панель, поле й «Надіслати» над клавіатурою; налаштування за кнопкою.
- Після надсилання на телефоні клавіатура закривається; рамка фокуса не заходить на кнопки.

## 2. Повернені функції попереднього чату
| Функція | Як працює | Де |
|---|---|---|
| «Не знаю, що відповісти» | Після відповіді Lexi. Запит `send('lesson', …)` з тим самим текстом, що в старому чаті (`helpPrompt`), з профілем навчання. Підказка + один приклад; «Вставити й відредагувати» кладе його в поле, нічого не надсилає. XP не дає. | Вільна розмова, говоріння, життєва ситуація |
| Стиль вільної розмови | «Розмова · легкі виправлення» (типово), «Викладач · пояснення помилок», «Повільна практика». Іде як наявний `extra.style` рушія. Розмова не скидається; запам'ятовується (`leren_ai_style`). | Налаштування чату |
| Легкі виправлення | У стилі «Розмова»: під відповіддю «Краще: …» і «Чому?». У стилях «Викладач»/«Повільна» та сценаріях — повна панель. До списку помилок: як у старому чаті (у легкому стилі — лише суттєві). | Відповідь Lexi |
| Закріпити виправлення | Кнопка біля кожного виправлення: написати виправлену фразу, «Зіставити зі зразком» (регістр і розділові знаки не враховуються), «Покажи ще один приклад», «Повернутися до розмови». Вимову не оцінює. XP не дає. | Історія |
| Автоозвучення | Кожна відповідь Lexi озвучується сама; перемикач «Автоматично озвучувати відповіді Lexi» (типово увімкнено, `leren_lexi_autovoice`). Нове повідомлення зупиняє попереднє озвучення. Показується, лише якщо пристрій уміє озвучувати. | Налаштування чату |

Тексти — українською, англійською, французькою, арабською (RTL).

## 3. AI-іспит у Concept B
Пробний іспит говоріння A1.1 і перевірка письма: палітра TEST-030 (світла й темна «C»), аватар Lexi 56/72 px біля відповідей, бульбашки й виправлення як у чаті, одна картка поля (на телефоні мікрофон-іконка). Логіка іспиту (питання, повтор, збереження, «Почати заново», «← Іспит») не змінена. Скриншоти «до/після»: `screenshots/test-033/exam-*.png`.
