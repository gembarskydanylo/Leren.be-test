# Контракт Lesson Help: `bridge.lexi('lesson', ctx)` (TEST-041, специфікація)

**Стан:** лише специфікація.
- Інтерфейс, кнопки, рушій і Worker у межах цього документа **не змінювались**.
- Реалізація — після погодження. Кнопки на екранах уроку робить Codex.

## 1. Чому зараз немає контексту

Канал передачі вже працює:
```
bridge.lexi / lexiOpen('lesson', ctx) → lexiMount → mountLexiChat({context}) → chat.js lessonContext → LerenLexi.send → profile → Worker learnerNotes
```
Але **жоден екран уроку його не викликає**:
- `bridge.lexi` передається в Learning Path, проте не використовується;
- вкладка «Допомога в уроці» в меню Lexi відкривається з порожнім `ctx`.

Те саме в TEST-033 і TEST-037.

## 2. Виклик

```js
bridge.lexi('lesson', {
  topic: 'Begroeten',               // назва розділу
  lesson: 'Les 3 · Hoe heet je?',   // назва уроку
  exercise: {kind: 'quiz', question: 'Hoe heet je?', expected: 'Ik heet …'},
  answer: 'Ik heet Anna'            // лише якщо учень уже відповів
})
```

`ui`, `target` і `level` **викликач не передає**: застосунок бере їх зі свого стану (`lexiCtx`: `uiLang`, `targetLang`, `curLevel`). Так екран не може підмінити мову чи рівень. Якщо ці поля передати, вони ігноруються.

## 3. Поля

| Поле | Джерело | Допустимі значення / ліміт | Якщо некоректне |
|---|---|---|---|
| `ui` | стан застосунку | `uk` `en` `fr` `ar` | `uk` |
| `target` | стан застосунку | `nl` `fr` `en` | `nl` |
| `level` | стан застосунку | `a11` `a12` `a21` | `a11` |
| `topic` | екран | рядок, ≤ 60 | обрізається; порожній — не надсилається |
| `lesson` | екран | рядок, ≤ 80 | обрізається |
| `exercise.kind` | екран | `study` `quiz` `build` `listen` `write` `talk` | відкидається |
| `exercise.question` | екран | рядок, ≤ 200 | обрізається |
| `exercise.expected` | екран | рядок, ≤ 200 (зразок відповіді з курсу) | обрізається |
| `answer` | екран | рядок, ≤ 200 (відповідь учня) | обрізається |

**Мова пояснення** — `explain` з TEST-041: за замовчуванням мова інтерфейсу.

Усі рядки проходять `clip()` рушія:
- керівні символи видаляються;
- пробіли стискаються;
- довжина обрізається.

У Worker вони вставляються в промпт через `clean()` у «лапках» як **матеріал, а не інструкції**. Правило проти prompt injection уже є і перевіряється в `lexi-worker.cjs`.

## 4. Безпека й приватність

**Ніколи не передаються:** uid, e-mail, ім’я, акаунт, XP, серії, бали, історія уроків, аудіо.
- `context()` у рушії пропускає лише перелічені поля. Те, що інші поля відкидаються, перевіряє `lexi-engine.cjs`.
- `answer` — єдиний текст, який пише сам учень. Він іде лише після натискання «Запитай Lexi» на екрані вправи, автоматично — ніколи.
- `expected` — дані курсу, не персональні.
- Слова для повторення й помилки (`learning.weak`, `mistakes`) і далі передаються, як у TEST-031: до 8 слів по 80 символів. Це навчальні дані, а не дані людини.
- Голос не записується. Розпізнаний текст учень перевіряє перед надсиланням.

## 5. Що треба змінити під час реалізації (після погодження)

1. **`engine.js` `context()`** — нові поля `kind` (перелік допустимих значень) і `expected` (≤ 200). `profile()` передає їх так само, як `question` і `answer`.
2. **`ai-worker.js` `learnerNotes()`:**
   - рядок `exercise type: …`;
   - рядок `expected answer from the course: «…» (do not reveal it before the learner tries; use it to check the answer)`.
3. **`app.js`** — `lexiCtx(s, extra)` уже зливає `ctx`. Потрібна лише обгортка, яка розгортає `exercise` в плоскі поля.
4. **Кнопки на екранах (Codex):** класичний урок (`newRound` / study / quiz / build), Learning Path (nl), Course Player (en / fr).
5. **Тести:**
   - для кожного типу вправи — поля доходять до промпту;
   - персональні поля відкидаються;
   - для кожного поля перевіряється ліміт і некоректне значення;
   - `answer` відсутній, доки учень не відповів.

## 6. Сумісність

- Старий Worker ігнорує невідомі поля `profile.kind` / `profile.expected`, тож відповідь не ламається.
- TEST-037 зберігає розмову за ключем `[…, ctx.topic, ctx.lesson, ctx.question, ctx.answer, ctx.send]`. Нові поля треба додати до ключа, інакше Lexi відновить розмову з іншої вправи.
