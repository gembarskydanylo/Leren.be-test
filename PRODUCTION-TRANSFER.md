Рахунок зливається максимумом: незалежні офлайн-прирости не сумуються як серверні події. Для точного багатопристроєвого XP потрібен окремий журнал подій; для рейтингів/матеріальних призів поточна клієнтська модель непридатна.

- Реально виконані перевірки та обмеження — TESTING-JOURNAL.md / TEST-006. Нових ключів API чи витрат сервісів немає; правила Firebase та production цього експерименту не змінено.
